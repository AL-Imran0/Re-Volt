# ⚡ LexVolt

**AI-Style Legal Assistant Interface for Re-Volt Beverage Ltd.**
*A single-page legal chatbot concept covering Bangladeshi business law.*

---

## Overview

LexVolt is a browser-based, single-file web application that simulates an AI legal assistant for a fictional company, **Re-Volt Beverage Ltd.** — a premium electrolyte drink manufacturer based in Dhaka, Bangladesh. It presents a polished chatbot UI where users can ask business-law questions and receive structured, example-rich legal guidance tied to Re-Volt's specific situation (e.g. "What happens if a distributor's cheque bounces?").

The project runs entirely client-side — no server, no database, no external API calls. It is best understood as a **UI/UX and content prototype** for a vertical legal-tech product, rather than a live AI system.

---

## Key Features

- **Three-panel chat interface** — company profile & law topics (left), chat window (center), tools & quick queries (right)
- **Keyword-based response engine** — matches user questions to one of five pre-written legal topic modules
- **Voice input & output** — browser-native speech recognition (mic input) and speech synthesis (auto-speak replies)
- **Dark/light theme toggle** with animated glassmorphism styling
- **Session tools** — RJSC registration guide, legal notice drafting, compliance checklist, payment recovery calculator, BSTI/BFSA compliance guide
- **Chat history & export** — conversations persist via browser `localStorage` and can be exported
- **Verify-online links** — every response ends with real Google search links so claims can be independently checked

---

## How It Works

1. **User input** — the person types a question or uses the mic button to speak one.
2. **Keyword matching** — the app scans the message for relevant terms (e.g. "cheque," "bounce," "partnership," "sale of goods") and selects a matching response template.
3. **Templated legal response** — the matched template is a fully pre-written HTML block including:
   - Bolded legal terms and exact section numbers
   - A realistic Re-Volt-specific worked example (with figures in ৳ BDT)
   - Step-by-step procedures where relevant (e.g. cheque-bounce recovery timeline)
   - Warning/alert boxes for critical deadlines
   - A closing set of Google search links for verification
4. **Display & optional narration** — the response renders in the chat window, and if auto-speak is enabled, it's read aloud via the browser's speech synthesis.

> **Note:** The code includes a detailed `SYSTEM_PROMPT` string written in the style of an LLM system prompt (formatting rules, tone, legal knowledge base). This currently serves as **internal documentation of intended AI behavior** — it is not sent to any live model. All responses are generated by JavaScript keyword-routing logic, not real-time AI reasoning.

## Legal Topics Covered

| Law | Focus Area |
|---|---|
| **Partnership Act 1932** | Founder liability, partnership deed, registration requirements |
| **Companies Act 1994** | RJSC incorporation, director duties, licensing (Trade Licence, TIN, VAT, BSTI, BFSA) |
| **Contract Act 1872** | Valid contracts with suppliers/distributors/retailers, breach & damages |
| **Sale of Goods Act 1930** | Product quality standards, ownership transfer, unpaid seller rights |
| **Negotiable Instruments Act 1881 (§138)** | Full cheque-dishonour recovery procedure — notice, waiting period, criminal filing, penalties |

## Tech Stack

- **HTML5 / CSS3** — single-file layout, custom properties (CSS variables) for theming
- **Vanilla JavaScript** — no frameworks; handles routing, state, voice APIs, and localStorage
- **Font Awesome** — icon set
- **Google Fonts** — Rajdhani, Exo 2, JetBrains Mono, Lora
- **Browser APIs** — `SpeechRecognition` (voice input), `SpeechSynthesis` (voice output), `localStorage` (chat history)

---

## Limitations / Honest Disclosure

- Responses are **not generated by a live AI model** — they are static, pre-written content selected via keyword matching.
- Legal information is illustrative and example-driven; it is **not a substitute for professional legal advice**.
- To evolve this into a genuine AI assistant, the existing `SYSTEM_PROMPT` would need to be sent to a real LLM API (e.g. the Claude API) in place of the current if/else routing logic.
